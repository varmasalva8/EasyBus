' ---------- Annotations / Scaling Points ----------
note right of BDB
  Scaling & Safety:
  * Partition booking tables by time / shard by region
  * Use read replicas for heavy-read use cases
  * Use idempotent consumers & event dedupe keys
  * Use Redis + optimistic locking for seat reservations
end note

note left of PS
  Payments:
  * Do not store PANs - use tokenization / vault
  * Keep PCI-scope minimized
  * External payment gateway integrations pluggable
end note

note bottom
  Security & Best Practices:
  * Use OAuth2 / OIDC with RS256-signed JWTs
  * API Gateway enforces rate-limits, WAF, auth checks
  * mTLS (Service Mesh) for service-to-service auth
  * Centralized logging, tracing, and alerting
  * Use schema migrations (Flyway/Liquibase) and feature toggles
end note
